El administrador debe configurar una vez Supabase. No introduzcas aquí claves secretas de servicio.

Primera instalación: crear base de datos

1. Crea un proyecto gratuito en Supabase.
2. En SQL Editor → New query, copia y ejecuta el SQL de abajo.
3. En Authentication → Users, crea cada usuario con correo y contraseña numérica de 6 o más dígitos.
4. En Table Editor → profiles, crea un perfil con el UUID del usuario, su nombre y rol admin o worker.
5. En Project Settings → API Keys, copia la URL del proyecto y la clave pública (publishable/anon) en los campos de arriba. Nunca uses la service_role/secret.

La conexión se guarda en este navegador. Cada móvil necesita la misma URL y clave pública, pero cada trabajador entra con su propia cuenta.
